# Archaeological Dig – Full-Body Interactive Game

## Overview

This repository contains the final project for the *Interactive Systems* course at Universitat Pompeu Fabra. The project explores **full-body interaction** in an educational game format where players physically engage in a virtual archaeological dig.

The experience is designed for two players and aims to make learning about fossils and dinosaurs engaging through movement, discovery, and collaboration.

## Project Description

Players are immersed in a desert environment containing sand piles with hidden items. A central screen displays the name and image of a fossil. Both players must search for the correct object beneath the sand and place it in their designated boxes. The game continues with new items until the full list is completed.

## Game Features

- **Environment**: Desert with interactive terrain and fossil elements
- **Input**: Full-body tracking (shovel movement, grasp and release actions)
- **Interaction Design**:
  - X axis → left/right movement
  - Y axis → forward/backward
  - Z axis → up/down
  - 3 degrees of freedom in translation
- **Gameplay Loop**:
  1. Display fossil name + image
  2. Players search for the correct item
  3. Place fossil in personal box
  4. Repeat until all fossils are found

- Kinect / camera-based motion tracking (if applicable)
- Asset sources: Flaticon, Freepik

# Excavación Arqueológica – Juego Interactivo Corporal

## Descripción

Este repositorio contiene el proyecto final de la asignatura *Sistemas Interactivos* de la Universitat Pompeu Fabra. El objetivo es desarrollar un juego educativo con interacción corporal completa, donde los jugadores participan en una excavación arqueológica virtual.

Diseñado para dos jugadores, el juego promueve el aprendizaje de fósiles y dinosaurios mediante mecánicas físicas de búsqueda y recolección.

## Mecánica del Juego

El entorno es un desierto con montículos de arena que ocultan objetos. Una pantalla muestra el nombre e imagen de un fósil. Los jugadores deben buscar el fósil correspondiente y colocarlo en su caja asignada. La dinámica se repite hasta completar todos los objetos.

## Elementos Interactivos

- **Entorno**: Desierto con fósiles escondidos
- **Input**: Seguimiento de cuerpo completo (palas, agarre y suelta)
- **Diseño de interacción**:
  - Eje X → movimiento izquierda/derecha
  - Eje Y → movimiento adelante/atrás
  - Eje Z → movimiento arriba/abajo
  - 3 grados de libertad de traslación
- **Flujo de juego**:
  1. Mostrar nombre e imagen del fósil
  2. Buscar el objeto correcto
  3. Colocar en la caja
  4. Repetir hasta completar

## Herramientas

- Unity3D (o motor similar)
- Tecnología de seguimiento corporal (Kinect, cámara)
- Recursos gráficos: Flaticon, Freepik
